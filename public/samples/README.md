# Sample structures

- `1D66.pdb`: existing project sample; GAL4 protein–DNA complex. Original metadata and attribution are preserved in the PDB file. Source: https://www.rcsb.org/structure/1D66
- `3RGK.pdb`: existing project sample; crystal structure of human myoglobin, K45R mutant. Original metadata and attribution are preserved. Source: https://www.rcsb.org/structure/3RGK
- `ethanol.xyz`: nine-atom illustrative coordinates authored for this application. Not energy minimized; use for display demonstrations, not scientific calculations. Bonds are inferred from interatomic distances by the renderer.

Samples are served with the app, so opening them does not contact an external molecular database.
